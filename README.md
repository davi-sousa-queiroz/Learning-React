# ⚛️ React Projects 🧑‍💻

A collection of projects I'm building while learning **React**. This repository documents my progress through hands-on projects, helping me understand React concepts, improve my problem-solving skills, and gradually build more complex applications.

## 📂 Projects

| # | Project | Description | Concepts Practiced |
|---|---|---|---|
| 01 | **Personal Dashboard** | A simple, static dashboard built with reusable components. | Components, JSX, Props, Conditional Rendering, Lists |
| 02 | **Hangman** | An interactive version of the classic word-guessing game. | Events, State, User Input, State Updates, Rendering |
| 03 | **GitHub Profile Explorer** | An application that searches for and displays GitHub user profiles. | Hooks, useEffect, Forms, APIs, Async/Await, Loading & Error States |
| 04 | **ConvertHub** | A multi-page conversion application with currency conversion and other JavaScript-based calculations. | React Router, Navigation, URL Parameters, API Integration, Reusable Components, Application Architecture |

## 📁 Exercises

The repository also includes an `exercises/` folder containing smaller coding exercises completed while learning React. These exercises are used to practice individual concepts, experiment with React features, and reinforce what I've learned through hands-on practice.
